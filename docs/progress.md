# Прогресс

## ЛР 1 — Старт проекта на React и TypeScript

### Результат
Создан каркас приложения «Учебный менеджер» (React + TypeScript + Vite).  
Настроен начальный экран с названием, описанием и заглушкой списка заданий.  
Подготовлены README, .node-version, .gitignore. Проект отправлен в GitHub.

### Проверки 
1. Проект создан через Vite, зависимости установлены.
2. Dev-сервер запускается, экран отображается в браузере.
3. Проверка типов и сборка проходят (`npm run build`).
4. Preview показывает готовую сборку.
5. В корне есть README, .node-version, .gitignore, docs/, frontend/.
6. Изменения закоммичены и отправлены в удалённый репозиторий.

## ЛР 2 — Страницы и навигация

### Результат
Добавлены главная страница, список заданий (≥5 демонстрационных записей),
карточка по id, экран создания (заглушка), общий layout и React Router.  
Неизвестный адрес и отсутствующая запись обрабатываются отдельно.

### Проверки
1. `/` — главная страница.
2. `/assignments` — список из 5 заданий.
3. Открыты две разные карточки, содержимое различается.
4. Прямое открытие `/assignments/a1` и обновление страницы работают.
5. `/assignments/new` — заглушка и общая навигация.
6. `/*` — «Страница не найдена».
7. `/assignments/*` — «Задание не найдено».
8. `npm run build` проходит без ошибок.

### Коммит ЛР 2
`Lab 2: add pages and navigation`
